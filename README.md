# My Device Manager

LuCI-приложение для OpenWrt 25.12.x, которое автоматически обнаруживает устройства в локальной сети и показывает доступную информацию о них.

## Обнаружение устройств

Список объединяет данные DHCP, mDNS, таблицы соседей и подключённых Wi-Fi-клиентов. Отображаемое имя берётся из mDNS, имени хоста DHCP или другого доступного источника; если имя не удалось определить, показывается нейтральная подпись. Если UFP уже установлен, приложение может дополнительно показать определённого производителя или модель. Для Wi-Fi-клиентов доступны текущий диапазон, канал, уровень сигнала, стандарт Wi-Fi, скорости соединения и счётчики байтов от hostapd.

Устройства не нужно регистрировать в My Device Manager, переименовывать в приложении или отдельно регистрировать в DHCP. Пока для MAC-адреса не сохранено ограничение диапазона, показывается пометка **«Устройство не зарегистрировано»**.

## Выбор диапазона Wi-Fi

Для каждого обнаруженного устройства доступен выбор:

- **2,4 + 5 ГГц — выбор клиента:** My Device Manager не вводит собственное ограничение, а клиент сам выбирает диапазон.
- **Только 2,4 ГГц:** приложение запрещает этому MAC-адресу подключаться к точкам доступа других диапазонов.
- **Только 5 ГГц:** приложение запрещает этому MAC-адресу подключаться к точкам доступа других диапазонов.

Выбор действует по MAC-адресу Wi-Fi-клиента. Если на устройстве включена рандомизация MAC и адрес изменится, правило нужно будет настроить для нового адреса.

Ограничения применяются через Wi-Fi ACL OpenWrt. Перед изменением приложение проверяет наличие точки доступа на выбранном диапазоне с совместимыми SSID и настройками защиты и отказывается от изменения при обнаружении конфликта с ручными списками MAC. Само применение ограничения может кратковременно перезапустить Wi-Fi и разорвать соединение. **Обновление приложения не меняет текущие настройки Wi-Fi и не применяет ограничений автоматически** — они меняются только после выбора режима для конкретного устройства в интерфейсе.

Приложение не меняет firewall, `tc`, mwan3, Tachyon или маршрутизацию прокси. Ограничение относится только к допуску MAC-адреса на точки доступа других диапазонов; когда выбраны оба диапазона, решение остаётся за клиентом.

## Установка и обновление

В SSH-сессии под `root`:

```sh
wget -O /root/mdm-install.sh https://github.com/MakeHomeWiFiGood/my-device-manager/releases/download/v0.2.28/install.sh
sh /root/mdm-install.sh check &&
sh /root/mdm-install.sh reinstall
```

Команда `reinstall` проверяет резервные копии и заменяет только файлы My Device Manager, отслеживаемые установщиком. Она сохраняет `/etc/config/my_device_manager`, а также конфигурацию DHCP, Wi-Fi, firewall, mwan3 и Tachyon. mDNS и UFP опциональны: установщик не устанавливает и не включает их.

Для удаления приложения и восстановления файлов, существовавших до первой установки:

```sh
sh /root/mdm-install.sh uninstall
```

Сохраняй `/root/mdm-install.sh` до тех пор, пока не убедишься, что удаление не потребуется. Резервные копии и манифесты находятся в `/root/.my-device-manager`.

## Ограничения

Точную модель устройства удаётся определить не всегда. Скорости Wi-Fi и счётчики байтов — текущий снимок hostapd; счётчики могут сбрасываться после отключения и повторного подключения клиента. Ограничение скорости для отдельного устройства не реализовано. CI проверяет сборку исходного архива и установщик, но не заменяет проверку на самом роутере.
